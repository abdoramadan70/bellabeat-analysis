# Bellabeat Smart Device Usage Analysis

## Project Overview
This project analyzes smart device usage data to identify trends in user activity and develop marketing recommendations for Bellabeat.

## Tools
- SQL
- BigQuery
- Tableau
- Excel

## Analysis
The analysis explored daily activity patterns, average steps and calories burned, and the relationship between activity level and calories burned.
Key findings:
- Wednesday had the highest average number of steps.
- Tuesday had the lowest average number of steps.
- Higher activity levels were associated with higher calories burned.
